# ระบบบันทึกชั่วโมงการฝึกทักษะวิชาชีพ (Skill Hours)

เว็บแอปสำหรับเก็บชั่วโมงการฝึกทักษะวิชาชีพของนักศึกษา
สาขาวิชาวิศวกรรมคอมพิวเตอร์และการสื่อสาร คณะวิศวกรรมศาสตร์และเทคโนโลยี
มหาวิทยาลัยเทคโนโลยีราชมงคลศรีวิชัย วิทยาเขตตรัง

**Stack:** PHP 8.3 + Apache 2 + MariaDB 11 (รันบน Docker Desktop) · Bootstrap 5 · ไม่ใช้ framework (อ่านโค้ดง่าย เหมาะกับโปรเจกต์จบ)

---

## เริ่มใช้งาน (Docker Desktop)

1. เปิด **Docker Desktop** ให้ทำงาน
2. เปิด Terminal ที่โฟลเดอร์โปรเจกต์ แล้วรัน

```bash
docker compose up -d --build
```

3. เปิดเบราว์เซอร์

| บริการ | URL |
|---|---|
| เว็บระบบ | http://localhost:8080 |
| phpMyAdmin | http://localhost:8081 (user `skillhours` / `skillhours_pass`) |
| MariaDB (จากเครื่อง) | `localhost:3307` |

ครั้งแรกระบบจะสร้างตารางและข้อมูลตัวอย่างให้อัตโนมัติ (จาก `database/init/*.sql`)

### บัญชีทดลอง (รหัสผ่านทุกบัญชี `password123`)

| บทบาท | ชื่อผู้ใช้ |
|---|---|
| ฝ่ายทะเบียน | `registrar` |
| อาจารย์ | `naret`, `phumin`, `surin`, `chaiwat`, `sayamon` |

### คำสั่งที่ใช้บ่อย

```bash
docker compose ps
```

```bash

```

```bash

```

ล้างฐานข้อมูลแล้วเริ่มใหม่ด้วยข้อมูลตัวอย่าง (**ข้อมูลเดิมจะหายทั้งหมด**):

## ความสามารถของระบบ

### นักศึกษา
- ดูชั่วโมงสะสม / เกณฑ์ (4 ปี = 100 ชม., เทียบโอน = 50 ชม.) และสถานะ **ครบ / ยังไม่ครบ**
- ดูชั่วโมงแยกตาม **ทักษะ** และตาม **อาจารย์** แต่ละท่าน
- ดูกิจกรรมที่อาจารย์โพสต์ และ **ส่งคำขอเข้าร่วม** (ยกเลิกคำขอได้)
- **ประวัติการเข้าร่วมกิจกรรม** ทั้งหมด พร้อมสถานะ
- **พิมพ์แบบบันทึกการฝึกทักษะวิชาชีพ** (A4 แนวนอน ตามแบบฟอร์มคณะ) หรือบันทึกเป็น PDF
- การแจ้งเตือนเมื่อได้รับอนุมัติ / ถูกมอบหมาย / บันทึกผลแล้ว

### อาจารย์
- **สร้างกิจกรรม** ให้นักศึกษาขอเข้าร่วม (กำหนดทักษะ ชั่วโมง จำนวนรับ วันปิดรับ สถานที่)
- **กำหนดวันและเวลา** ได้หลายวันต่อกิจกรรม
- อนุมัติ / ปฏิเสธคำขอ (ทีละคนหรือหลายคน)
- **มอบหมายกิจกรรมเฉพาะคน** เช่น นักศึกษา A ทำงาน 21 ชม. วันที่ 3, 4, 10 ต.ค.
- **ค้นหานักศึกษา** ด้วยรหัสนักศึกษาหรือชื่อ ดูรายละเอียดรายคน และพิมพ์แบบฟอร์มได้
- **บันทึกผล ผ่าน/ไม่ผ่าน** ปรับชั่วโมงรายคนได้
- ลายมือชื่ออาจารย์ผู้ควบคุม เลือกได้ว่า **เซ็นออนไลน์** (วาดด้วยเมาส์/นิ้ว/ปากกา หรือใช้ลายเซ็นที่บันทึกไว้) หรือ **กรอกชื่อ**

### ฝ่ายทะเบียน
- ค้นหานักศึกษาด้วยรหัส/ชื่อ กรองตามแผนการเรียน ปีที่เข้า และสถานะครบ/ไม่ครบ
- ดูชั่วโมงสะสม และ **พิมพ์แบบบันทึกทักษะ** เก็บเป็นหลักฐาน
- ภาพรวมสถิติ, **ส่งออก CSV (เปิดด้วย Excel)**
- จัดการผู้ใช้, **นำเข้านักศึกษาจาก CSV**, จัดการรายชื่อทักษะ, ภาคการศึกษา, ตั้งค่าเกณฑ์ชั่วโมง
- บันทึกการใช้งาน (audit log), API Keys, หน้าเชื่อมต่อ API มหาวิทยาลัย

## รองรับ API มหาวิทยาลัย (RMUTSV)

ออกแบบเป็น **adapter** แยกไว้ที่ `app/Integrations/UniversityApi/` สลับได้ด้วยค่าใน `.env`

| `UNI_API_DRIVER` | ความหมาย |
|---|---|
| `none` | ปิด |
| `mock` | ข้อมูลจำลอง (ค่าเริ่มต้น ใช้ทดสอบ) |
| `rmutsv` | เรียก REST API จริง — ตั้ง `UNI_API_BASE_URL`, `UNI_API_KEY`, `UNI_API_*_ENDPOINT` |

- `AUTH_MODE=hybrid` → ถ้าไม่มีบัญชีในระบบ จะลองเข้าสู่ระบบผ่าน API มหาวิทยาลัย แล้วสร้างบัญชีให้อัตโนมัติ
- ชื่อฟิลด์ JSON ของมหาวิทยาลัยจับคู่ได้ใน `app/config.php` → `field_map` (ไม่ต้องแก้โค้ด)
- ถ้ามหาวิทยาลัยใช้ LDAP/OAuth ให้สร้างคลาสใหม่ที่ implement `UniversityApiInterface`

### REST API ของระบบนี้ (ให้ระบบภายนอกดึงข้อมูล)

สร้าง key ที่เมนู **ฝ่ายทะเบียน → API Keys** แล้วส่งใน header `X-API-Key` หรือ `Authorization: Bearer`

| Method | Path | คำอธิบาย |
|---|---|---|
| GET | `/api/v1/health` | ตรวจสถานะ (ไม่ต้องใช้ key) |
| GET | `/api/v1/skills` | รายชื่อทักษะ |
| GET | `/api/v1/students?q=&program=&done=&year=&page=` | รายชื่อ + ชั่วโมงสะสม |
| GET | `/api/v1/students/{code}/summary` | สรุปชั่วโมงรายคน |
| GET | `/api/v1/students/{code}/records` | รายการที่บันทึกผลแล้ว |
| POST | `/api/v1/students/sync` | ระบบมหาวิทยาลัยส่งข้อมูลนักศึกษาเข้ามา (JSON) |

## โครงสร้างโปรเจกต์

```
├── docker-compose.yml       # web (PHP+Apache), db (MariaDB), phpmyadmin
├── Dockerfile
├── .env.example             # ตัวอย่างค่าตั้งค่า
├── database/init/           # schema + ข้อมูลตัวอย่าง (รันอัตโนมัติครั้งแรก)
├── docs/                    # เอกสารต้นฉบับ (PDF แบบฟอร์ม / รายชื่อทักษะ)
├── app/
│   ├── bootstrap.php, config.php, routes.php
│   ├── lib/                 # helpers, auth, layout, UI components
│   ├── Services/            # HoursService (คำนวณชั่วโมง), ActivityService, StudentQuery, UniversitySync
│   ├── Integrations/UniversityApi/   # adapter เชื่อม API มหาวิทยาลัย
│   ├── api/router.php       # REST API v1
│   └── pages/               # หน้าเว็บแยกตามบทบาท student / teacher / registrar / common
└── public/                  # DocumentRoot: index.php (front controller), assets
```
